# Pronto: rilasci

Versioni scaricabili di Pronto, il client per il centralino telefonico.

Scarica `Pronto-Setup-X.Y.Z.exe` dalla pagina [Releases](../../releases/latest). L'installazione è per utente e non richiede i permessi di amministratore. Gli aggiornamenti successivi si fanno dall'app, in Opzioni.

Qui non c'è il codice sorgente.
